# 积分系统 MVP 验收清单

本文用于 MVP 试运营前逐项验收。建议由产品负责人、队长主管、财务、管理员共同完成，所有验收结果请记录“通过 / 未通过 / 待确认”。

## 1. 管理端登录验收

| 项目 | 内容 |
| --- | --- |
| 验收入口 | `/login`、`/admin/dashboard` |
| 测试账号 | 管理员账号，以本地 seed 或测试环境配置为准 |
| 操作步骤 | 1. 打开登录页；2. 使用管理员账号登录；3. 查看是否进入管理首页；4. 点击退出登录 |
| 预期结果 | 登录成功进入 `/admin/dashboard`，退出后回到登录状态 |
| 常见问题 | 终端不在项目根目录、账号未 seed、浏览器缓存旧 session |
| 通过标准 | 管理员可正常登录、进入后台、退出登录 |

## 2. 队长端注册验收

| 项目 | 内容 |
| --- | --- |
| 验收入口 | `/leader/register` |
| 测试账号 | 新手机号、新用户名 |
| 操作步骤 | 1. 输入用户名、手机号、真实姓名、密码；2. 提交注册；3. 跳转绑定页或登录页 |
| 预期结果 | 新建 `User`，角色为 `LEADER`，密码使用系统 hash 规则 |
| 常见问题 | 用户名重复、手机号重复、密码确认不一致 |
| 通过标准 | 注册成功后无误报失败，未绑定用户进入绑定流程 |

## 17. 奖金测算验收

| 项目 | 内容 |
| --- | --- |
| 验收入口 | `/admin/bonus-settlement` |
| 测试账号 | 管理员或财务 |
| 操作步骤 | 1. 选择年度；2. 生成预览；3. 保存测算；4. 查看详情 |
| 预期结果 | 作废积分不计入，LEFT/SUSPENDED 不符合资格；满足基础资格的队长全部参与分配，不再限制前 40%；严重投诉取消资格；红线积分清零并取消资格；单人封顶 2000 |
| 常见问题 | 奖金池为 0、无符合资格队长、负分队长、严重投诉或红线导致取消资格 |
| 通过标准 | 档位权重、理论奖金、封顶扣减、未分配余额计算正确；队长端不展示个人奖金测算金额 |

当前试运行奖金规则：
- 年度完成带队次数 >= 8；
- 实习队长可参与，兼职 / 全职共用一个奖金池；
- 节假日积分只作为有效积分的一部分，不设硬性出勤门槛；
- A档前 20% 权重 1.8，B档 20%-50% 权重 1.3，C档 50%-100% 权重 1.0；
- 个人理论奖金 = 奖金池 ×（个人有效积分 × 档位权重）÷ 所有参与队长加权积分总和；
- 单人封顶 2000 元，封顶余额不二次分配；
- 严重投诉取消当年奖金资格；
- 红线行为奖金测算积分清零，并取消当年奖金资格。

| 操作步骤 | 依次打开 `/login`、`/leader/register`、`/leader/bind`、`/leader/dashboard`、`/leader/profile`、`/leader/scores`、`/leader/applications`、`/leader/applications/new`、`/leader/bonus`；完成登录、注册、绑定、查看积分、提交申请、上传证明图片和返回首页 |
| 预期结果 | 无横向滚动，表单单列展示，按钮高度至少 44px，错误提示清晰，积分卡片不挤压，返回按钮可用，首页按钮跳 `/leader/dashboard` |
| 常见问题 | 文件选择兼容性、长文字撑破卡片、键盘遮挡按钮 |

### 移动端专项检查步骤

1. 打开浏览器开发者工具，分别切换到 375、390、430、360、393 宽度。
2. 检查队长端页面是否出现横向滚动条。
3. 检查注册、绑定、申请表单是否为单列布局，主要按钮是否满宽或易点击。
4. 在 `/leader/applications/new` 选择证明图片，确认能触发相册/拍照选择，上传成功或失败提示不被遮挡。
5. 检查 `/leader/scores`、`/leader/applications` 是否使用卡片列表展示，不需要横向拖动表格。
6. 检查 `/leader/bonus` 是否只展示规则说明、积分、带队次数和基础参与条件，不展示预计奖金金额。
7. 使用微信内置浏览器至少抽测登录、积分查看、申请提交和图片上传。
