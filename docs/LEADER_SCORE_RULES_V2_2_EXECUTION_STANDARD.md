# 队长积分规则 V2.2 执行标准与审核要求

本文件用于规范队长积分 V2.2 的后台执行、审核、扣分、作废、申诉、奖金资格判定和榜单展示口径。

如系统配置与本文件冲突，以最新确认的积分规则版本和后台配置为准。

规则调整需记录生效日期，不追溯已生成积分，除非通过作废、重算或人工补录处理。

## 1. 文档使用说明

| 项目 | 说明 |
| --- | --- |
| 适用对象 | 队长管理人员、产品经理、积分审核人员、客诉处理人员、财务 / 奖金测算人员、系统维护人员 |
| 使用场景 | 加分审核、扣分录入、专项补录、积分作废、申诉复核、奖金资格判断、榜单口径说明 |
| 与队长端展示规则区别 | 队长端只展示可理解的规则说明；本文包含后台审核证据、边界判断、扣分和资格处理细则 |
| 与 ScoreRule 配置关系 | ScoreRule 是系统执行配置；本文是人工审核和业务判断标准。配置变更必须记录生效日期 |
| 历史数据处理 | 历史积分不因规则修改自动变化；错误记录走作废、重算或人工补录 |

## 2. 积分审核总原则

1. **有规则依据**：每一笔加分、扣分、作废都必须对应明确规则或管理层确认依据。
2. **有证据材料**：截图、链接、后台记录、聊天记录、客诉材料、排班记录等应尽量留存。
3. **有审核记录**：审核通过、拒绝、作废、扣分、申诉复核均应在系统中留痕。
4. **有可追溯台账**：所有积分最终进入 ScoreRecord 台账，禁止线下口头加减分。
5. **有申诉路径**：扣分和重大处理需保留一次申诉机会。
6. **不口头加分 / 不口头扣分**：没有系统记录的积分不作为排行榜和奖金测算依据。
7. **不删除历史积分**：错误记录走作废，台账保留原始记录和作废原因。
8. **规则调整不追溯**：新规则自生效日期向后执行；历史修正需走作废重算或人工补录。

## 3. 基础带队积分执行标准

当前规则：

```text
基础带队积分 = 1分/团 + 1分/天
```

执行口径：

- 主队、副队、跟队同分。
- 实习队长与正式队长同分。
- 暂不区分半天，0.5 天按 1 天，1.5 天按 2 天。
- 团期取消不生成基础分。
- 轻微失误保留基础分，另行扣分。
- 严重投诉、虚假行为、红线行为触发年度清零和奖金资格取消，不在基础分生成时直接处理。

基础积分生成条件：

1. 团期状态为已完成。
2. 队长实际完成带队。
3. 实际带队天数 >= 1。
4. 队长状态为实习或正式。
5. 未重复生成。
6. 团期结束日期落在 ACTIVE 积分年度。
7. `BASE_TRIP` 规则启用。

| 项目 | 执行标准 | 是否自动生成 | 是否需要人工审核 | 常见问题 | 处理方式 |
| --- | --- | --- | --- | --- | --- |
| 团期状态 | 仅 `COMPLETED` 可生成 | 半自动 | 需要管理员确认状态 | 销转表导入后仍是待出行 | 先确认实际出行结束再改状态 |
| 带队完成 | `TripLeader.isCompleted = true` | 半自动 | 需要管理员核对 | 队长临时未出队 | 不勾选完成，不生成 |
| 带队天数 | `actualWorkDays > 0`，半天向上取整 | 自动计算 | 需要人工填写或确认 | 0.5 天如何处理 | 按 1 天计 |
| 队长状态 | 实习 / 正式可生成 | 自动校验 | 无 | 离职队长历史带队 | 离职或暂停状态不生成新积分 |
| 重复生成 | `baseScoreRecordId` 为空 | 自动校验 | 无 | 重复点击生成 | 系统跳过已生成记录 |
| 积分年度 | 团期结束日期被 ACTIVE 年度覆盖 | 自动校验 | 无 | 找不到积分年度 | 到积分年度管理新增或启用年度 |
| 规则状态 | `BASE_TRIP` 启用且当前生效 | 自动校验 | 无 | 规则停用 | 启用规则后再生成 |

## 4. 节假日贡献积分执行标准

| 规则 | 分值 | 执行标准 | 后台处理方式 |
| --- | ---: | --- | --- |
| 五一出勤贡献 | +15 | 满足公司五一排班要求 | 后台专项加分 |
| 国庆出勤贡献 | +15 | 满足公司国庆排班要求 | 后台专项加分 |
| 五一国庆双节额外贡献 | +10 | 两个节假日均满足贡献认定 | 后台专项加分 |
| 公司未安排但人工认定 | +10 / 节假日 | 队长按要求接龙可带，未挑团，因公司未安排未出队 | 后台专项加分 |

执行说明：

1. 不是只带 1 天就自动给分。
2. 需满足公司排班要求。
3. 不挑团、不临时拒绝、不失联。
4. 公司未安排但队长按要求接龙可带，需要人工认定。
5. 节假日积分不需要队长主动申请。
6. MVP 阶段由后台专项加分补录。

| 场景 | 是否可认定 | 原因 | 处理方式 |
| --- | --- | --- | --- |
| 按要求接龙，可接受合理安排并完成出队 | 可认定 | 符合排班贡献 | 按节假日贡献加分 |
| 接龙后只挑特定路线，不接受合理安排 | 不可认定 | 不符合排班配合要求 | 不加分 |
| 临时拒绝或失联 | 不可认定 | 影响排班稳定性 | 不加分，必要时记录管理备注 |
| 公司未安排但队长全程可出勤 | 可人工认定 | 公司原因未安排 | 专项加分 10 分 / 节假日 |
| 只带 1 天但未满足排班要求 | 不可自动认定 | 节假日贡献不是单日出队奖励 | 由管理人员判断是否另行补录 |

## 5. 传播加分审核标准

传播类年度有效积分上限：80 分。

超过 80 分仍可记录贡献，但超出部分不计入年度有效积分、排行榜和奖金测算。

### 5.1 朋友圈带队分享

| 项目 | 标准 |
| --- | --- |
| 分值 | +3 分 / 次 |
| 团期要求 | 必须绑定团期 |
| 次数限制 | 每团最多 1 次 |
| 证据要求 | 群像照片 + 本次带队 / 路线相关文字；截图体现发布时间 |
| 发布时间 | 内容需保留 24 小时 |
| 审核通过 | 内容能证明与本次带队或路线相关，不要求硬广 |
| 不通过 | 无群像照片、无路线相关内容、截图无发布时间、明显非本团内容 |
| 常见争议 | 文案较生活化是否算 | 只要能体现路线或带队相关，可通过 |
| 后台处理 | 队长申请，审核通过生成积分；同团重复申请拒绝 |

### 5.2 朋友圈日常分享 / 推广

| 项目 | 标准 |
| --- | --- |
| 分值 | +1 分 / 次 |
| 团期要求 | 不强制绑定团期 |
| 内容范围 | 招募、活动推文、队长故事、路线推荐、品牌宣传 |
| 证据要求 | 截图体现内容和发布时间 |
| 审核通过 | 单纯转发公司推文也可给分 |
| 不通过 | 与行走20岁无关、截图不完整、无法判断发布时间 |
| 后台处理 | 队长申请，审核通过生成积分 |

### 5.3 小红书简单分享

| 项目 | 标准 |
| --- | --- |
| 分值 | +3 分 / 次 |
| 内容要求 | 配图 + 行走20岁标签 |
| 可见性 | 必须公开可见 |
| 证据要求 | 提交链接 + 截图 |
| 次数限制 | 同一团期小红书最多计 1 篇 |
| 审核通过 | 链接可打开，截图和内容符合基础要求 |
| 不通过 | 不公开、无配图、无品牌标签、无法打开链接 |
| 后台处理 | 如同团已有要求版通过，不再按简单版重复计分 |

### 5.4 小红书要求版

| 项目 | 标准 |
| --- | --- |
| 分值 | +5 分 / 次 |
| 内容要求 | 带队心得或路线分享，正文不少于 100 字 |
| 可见性 | 必须公开可见 |
| 证据要求 | 提交链接 + 截图 |
| 次数限制 | 同一团期小红书最多计 1 篇 |
| 互斥规则 | 达到 5 分标准按 5 分计，不再重复计 3 分 |
| 不通过 | 字数不足、内容与路线无关、不公开、链接不可访问 |
| 后台处理 | 与简单分享互斥，按高标准认定 |

### 5.5 视频号 / 抖音

| 项目 | 标准 |
| --- | --- |
| 分值 | 每 10 个小红心 5 分 |
| 单条上限 | 30 分 |
| 可见性 | 必须公开可见 |
| 证据要求 | 链接 + 小红心截图 |
| 截图时间 | 以提交时截图为准 |
| 审核通过 | 链接可打开，截图显示小红心数量 |
| 不通过 | 无链接、截图缺失、数据无法识别、疑似伪造 |
| 后台处理 | 审核人员按小红心数量填写批准分值 |

### 5.6 AI 与虚假内容

| 场景 | 处理标准 |
| --- | --- |
| AI 辅助润色 | 允许 |
| AI 编造不存在的带队经历 | 不允许，按虚假行为处理 |
| 搬运他人内容冒充原创 | 不允许，拒绝加分，情节严重按虚假行为 |
| 伪造截图 / 伪造小红心数据 | 按虚假行为处理 |
| 传播数据有争议 | 以提交时截图和可访问链接为准 |

## 6. 服务贡献加分执行标准

| 规则 | 分值 | 触发条件 | 证据要求 | 审核人 | 允许队长申请 | 需要关联团期 | 不通过情形 |
| --- | ---: | --- | --- | --- | --- | --- | --- |
| 老队员复购 | +5 / 人 / 次 | 老队员完成复购出行，且与该队长促成有关 | 聊天记录 + 后台核实完成出行 | 积分审核人员 / 队长主管 | 是 | 否 | 无法证明与队长有关、出行未完成、同订单已归属他人 |
| 推荐新队长 | +10 / 人，年度最高 30 | 被推荐人通过培训成为实习队长，完成首次出队，并最终转正 | 推荐记录、培训和转正确认 | 队长主管 | 否 | 否 | 未转正、推荐关系不清 |
| 带教新人 | +10 / 次 | 新人完成跟团 / 出团、双方复盘，并最终转正 | 带教反馈、新人复盘、出团记录、转正确认 | 队长主管 | 否 | 是 | 新人未复盘、未转正、带教关系不清 |
| 结团填写反馈 | +1 / 团 | 结团后 48 小时内提交有效反馈 | 路线问题、队员反馈、协作反馈 | 队长主管 / 产品经理 | 否 | 是 | 敷衍、逾期、内容为空 |
| 队长结团总结推广 | +2 / 次 | 每团最多 1 次，推广行走20岁其他路线 | 截图或链接 | 积分审核人员 | 是 | 是 | 与推广无关、重复提交、证据不足 |

复购争议处理：

- 不强制要求队员提供订单信息，但后台必须能核实完成出行。
- 同一老队员每次复购都可计。
- 同一订单只能归属 1 名队长。
- 多个队长争议时，归属最主要促成复购的队长，由后台判断。

## 7. 扣分执行标准

| 规则 | 分值 / 处理 | 触发标准 | 证据要求 | 资格影响 |
| --- | --- | --- | --- | --- |
| 抽烟 | -20 | 带队期间在队员面前、公共区域、车上、室内、景区集合点等影响队员体验的抽烟行为 | 照片、视频、投诉、工作人员记录 | 记录扣分 |
| 迟到 | -20 | 未按集合要求提前到达，或晚于约定集合时间到达 | 签到、定位、聊天记录、现场反馈 | 不可抗力需提前报备 |
| 未穿队服 | -5 | 公司明确要求穿队服的集合日或指定场景未穿 | 照片、现场记录 | 记录扣分 |
| 未带基础物资 | -5 | 未带药包、对讲机、队旗等基础物资 | 出团检查、现场记录 | 记录扣分 |
| 有效投诉 | -15 | 服务态度、组织安排、流程执行、沟通响应、照顾队员等问题经核实成立 | 客诉记录、聊天记录、复核结果 | 年度累计 2 次取消当年奖金资格 |
| 严重投诉 | 年度积分清零 + 取消奖金资格 | 同一团期 3 名或 3 名以上队员投诉同一队长，或单个重大事件 | 客诉材料、处理记录、管理层确认 | 年度清零，取消资格 |
| 安全违规 | -30 | 未做中高风险安全告知、未录视频留证、未提醒救生衣、未及时保险报备、擅自组织高风险活动 | 安全记录、视频、现场记录、报备记录 | 年度累计 2 次取消当年奖金资格 |
| 虚假行为 | 年度积分清零 + 取消奖金资格 | 虚假截图、虚假传播数据、伪造复购证据、虚假反馈、代填评价、骗取积分 | 对比证据、系统记录、人工复核 | 年度清零，取消资格 |
| 红线行为 | 年度积分清零 + 取消奖金资格 | 红线类型以队长手册为准 | 队长手册、事件材料、管理层确认 | 年度清零，取消资格，并按原制度处理 |

扣分补充规则：

1. 同一事件原则上按最严重项处理。
2. 多个独立行为可分别处理，但需管理层确认。
3. 轻微失误保留基础分，另行扣分。
4. 所有扣分都要有证据和处理记录。

## 8. 年度积分清零与奖金资格取消标准

触发年度积分清零：

1. 严重投诉。
2. 虚假行为。
3. 红线行为。

触发奖金资格取消：

1. 严重投诉。
2. 虚假行为。
3. 红线行为。
4. 年度有效投诉累计 2 次。
5. 年度安全违规累计 2 次。
6. 队长状态为暂停 / 离职。
7. 年度带队次数不足 8 次。
8. 年度有效积分为 0。

注意：

- 当前系统不删除历史积分记录。
- 年度清零应保留台账和处理记录。
- 如系统暂未做物理清零，可在奖金测算中清零，并由 data-check 提醒。

## 9. 申诉处理标准

1. 每个事件允许一次申诉。
2. 队长需在收到处理结果后 3 个工作日内提交证据。
3. 超过 3 个工作日原则上不再受理。
4. 无新增证据的重复申诉不予受理。
5. 复核结果为最终处理结论。
6. 申诉统一放后台处理。
7. 申诉处理需保留操作记录。

## 10. 积分作废标准

以下情况走作废，不删除记录：

1. 录错积分。
2. 误生成积分。
3. 审核后发现材料不成立。
4. 扣分误判。
5. 规则适用错误。

作废后：

- 不计入队长端总分。
- 不计入排行榜。
- 不计入奖金测算。
- 台账保留。
- 需要填写作废原因。

## 11. 奖金规则执行标准

当前 V2.2 奖金规则：

1. 年度折算带队次数 >= 8 次。
2. 年度有效积分 > 0。
3. 状态不是暂停 / 离职。
4. 无严重投诉。
5. 无红线。
6. 无虚假行为。
7. 实习队长满足条件也可参与。
8. 兼职 / 全职共用奖金池。
9. 档位权重：
   - A档：前20%，权重1.8。
   - B档：20%-50%，权重1.3。
   - C档：50%-100%，权重1.0。
10. 单人奖金上限 2000。
11. 封顶余额不二次分配。
12. 队长端不展示预计奖金金额。

公式：

```text
个人理论奖金 = 奖金池 ×（个人有效积分 × 档位权重）÷ 所有参与队长加权积分总和
```

## 12. 榜单展示执行标准

1. 队长端开放前 50 积分榜。
2. 展示排名、队长昵称、队长等级、年度有效积分。
3. 不展示手机号、扣分原因、投诉原因、奖金金额。
4. 队长本人可看自己的积分明细、扣分项目和原因。
5. 不做月度公示。
6. 榜单为系统当前数据展示。

## 13. 后台执行流程

### 13.1 加分审核流程

1. 查看申请。
2. 检查规则。
3. 检查证据。
4. 检查是否超过上限或重复。
5. 审核通过 / 拒绝。
6. 生成 ScoreRecord。
7. 台账留痕。

### 13.2 后台专项加分流程

1. 选择队长。
2. 选择规则。
3. 填写原因。
4. 上传证据。
5. 提交。
6. 进入台账。

### 13.3 扣分录入流程

1. 选择队长。
2. 选择违规类型。
3. 填写事实说明。
4. 上传证据。
5. 确认是否影响奖金资格。
6. 生成扣分记录。
7. 通知队长或保留申诉入口。

### 13.4 作废流程

1. 进入积分详情。
2. 点击作废。
3. 填写原因。
4. 保存。
5. 确认总分、榜单、奖金测算不再计入。

## 14. 常见审核场景判断表
