## 一、为什么要做这套系统

队长的贡献不只体现在带队本身，还包括日常传播、内容分享、老队员复购、结团反馈、带教和其他服务投入。过去这些信息分散在不同记录里，查询和核对不够方便。

这套系统希望把积分规则、申请材料、审核结果和积分台账放到同一个地方。队长可以随时查看自己的积分和申请进度，后台也能按统一口径审核并保留记录，减少漏记、重复统计和口径不一致。

本轮还不是正式上线。我们先邀请 20 名队长把系统“用起来”，找出流程、提示、页面和规则展示中不顺手的地方，再决定后续是否扩大范围。

## 二、本轮内测要测什么

请大家重点完成以下内容：

1. 注册队长账号并登录。
2. 使用与队长档案一致的手机号，提交档案绑定申请。
3. 绑定审核通过后，进入队长端查看个人信息和积分页面。
4. 提交 3 条加分申请：
   - 1 条朋友圈日常分享 / 推广；
   - 1 条小红书要求版分享；
   - 1 条老队员复购或当前页面中的其他可选规则。
5. 每条申请至少上传 1 张测试证明图片。
6. 查看申请是否成功进入“待审核”，并在后台审核后查看“已通过”或“已拒绝”的结果。
7. 查看积分明细、积分中心和排行榜，确认页面能否正常打开、分值和状态是否容易理解。
8. 用手机完成一次完整操作，留意按钮、输入框、图片上传和页面滚动是否顺手。

后台会安排人员审核。为了同时验证两种结果，部分测试申请可能会被有意拒绝；这不代表对队长真实工作的评价。

## 三、操作流程

### 1. 打开系统

系统地址：

https://leader-score-system-268536-5-1439098102.sh.run.tcloudbase.com

常用入口：

- 登录：https://leader-score-system-268536-5-1439098102.sh.run.tcloudbase.com/login
- 队长注册：https://leader-score-system-268536-5-1439098102.sh.run.tcloudbase.com/leader/register
- 队长端首页：https://leader-score-system-268536-5-1439098102.sh.run.tcloudbase.com/leader/dashboard
- 提交加分申请：https://leader-score-system-268536-5-1439098102.sh.run.tcloudbase.com/leader/applications/new
- 我的加分申请：https://leader-score-system-268536-5-1439098102.sh.run.tcloudbase.com/leader/applications

推荐使用 Chrome、Safari 或微信内置浏览器。若页面打不开，请先截图并记录时间，再联系内测负责人。

### 2. 注册队长账号

1. 打开“队长注册”页面。
2. 填写用户名、手机号、真实姓名和密码。
3. 手机号必须与系统中的队长档案一致，否则无法匹配档案。
4. 密码请自行设置，不要使用微信、银行卡或其他重要账号的同一密码。
5. 点击“注册队长账号”。

如果提示用户名或手机号已注册，请不要重复创建账号，直接把截图发给内测负责人。

### 3. 绑定队长档案

1. 注册成功后，系统会进入档案绑定页面。
2. 核对姓名、手机号、区域和队长级别。
3. 信息无误后提交绑定申请，等待后台审核。
4. 审核通过后，重新进入队长端首页。

如果页面提示“未找到匹配档案”，请反馈注册手机号和姓名，由负责人核对档案。不要换手机号重复注册。

### 4. 提交加分申请

1. 登录队长端，进入“我的加分申请”。
2. 点击“提交加分申请”。
3. 选择要测试的积分规则。
4. 如果页面要求关联团期，请选择对应团期；没有合适团期时，可先测试不要求关联团期的规则。
5. 填写申请说明和证明材料；有证明链接时一并填写。
6. 上传证明图片并提交。
7. 返回“我的加分申请”，检查规则名称、申请分值和状态是否正确。

图片要求：

- 每条申请最多 3 张；
- 支持 JPG、PNG、WEBP；
- 单张不超过 5MB；
- 暂不支持 HEIC/HEIF，可先截图或转换格式后上传。

### 5. 查看审核结果和积分

后台审核后，请再次登录系统：

1. 在“我的加分申请”中查看审核状态。
2. 被拒绝的申请，检查是否能看到拒绝原因。
3. 审核通过的申请，检查积分记录是否增加。
4. 打开积分中心和排行榜，确认分值、排名和个人信息显示是否正常。

如果申请长时间处于“待审核”，一般是后台还未处理，不需要重复提交。

## 四、内测期间请注意

1. 不要共用账号，也不要把密码发到群里。
2. 不要上传身份证、银行卡、客户隐私、真实订单敏感信息等材料。
3. 可以使用接近真实的测试场景，但请对截图中的手机号、姓名、订单号等信息打码。
4. 不要把系统地址、后台截图、证明图片链接转发给非内测人员。
5. 提交后请等待页面反馈，不要连续点击按钮，以免产生重复记录。
6. 本轮数据用于系统测试，不作为正式积分或奖金发放依据；是否保留以后续通知为准。
7. 如果发现积分或页面信息明显不对，请先停止继续操作，截图后联系负责人，不要反复尝试。

发现问题时，请尽量把信息一次写全。可直接复制下面的模板：

```text
测试时间：

【操作步骤】
1.
2.
3.

【期望结果】

【实际结果】

【截图或录屏】
请勿包含密码、客户隐私或其他敏感信息。
```

问题分级：

- P0：无法注册、登录、绑定或提交申请；数据明显错乱；大面积图片或页面不可用。发现后请立即联系负责人，并暂停相关操作。
- P1：核心流程还能继续，但某一步明显异常，例如状态不刷新、个别图片失败或提示让人看不懂。
- P2：体验和文案问题，例如排版不舒服、按钮不好点、说明不清楚。

## 六、什么时候算完成内测

每位队长完成下面几项，就算完成本轮任务：

- 注册并成功登录；
- 提交档案绑定申请，并在审核通过后进入队长端；
- 提交 3 条加分申请，每条至少上传 1 张图片；
- 查看至少 1 条审核通过和 1 条审核拒绝的结果；
- 检查积分中心和排行榜；
- 有问题就按模板反馈，没有问题也请回复“已完成，暂未发现问题”。
