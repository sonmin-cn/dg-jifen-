# 队长积分规则 V2.2 完整版

本文用于 MVP 第二阶段试运营，规则从生效日期起向后适用。历史积分不自动重算；如需修正历史记录，应通过积分作废、重新生成或专项补录处理。

## 一、基础带队积分

公式：

```text
基础带队积分 = 1 分 / 团 + 1 分 / 天
```

系统配置：

```json
{
  "formula": "perTripPoints + actualWorkDays * perDayPoints",
  "perTripPoints": 1,
  "perDayPoints": 1,
  "roundActualWorkDays": "CEIL_TO_DAY"
}
```

规则说明：
- 暂不区分半天，0.5 天按 1 天，1.5 天按 2 天。
- 主队、副队、跟队同分。
- 实习队长与正式队长同分。
- 取消团不生成基础分。
- 轻微失误保留基础分，另行扣分。
- 严重投诉、虚假行为、红线行为不在基础分生成时直接处理，而是在年度清零 / 奖金资格中处理。

生成条件：
- 团期状态为 `COMPLETED`。
- 带队记录 `isCompleted = true`。
- 实际带队天数大于 0。
- 未生成过基础积分。
- 队长状态为实习或正式。
- `BASE_TRIP` 规则启用且当前生效。
- 存在覆盖团期结束日期的 ACTIVE 积分年度。

## 二、节假日贡献积分

节假日积分暂不由队长端申请，MVP 阶段通过后台专项加分补录。

| 规则编码 | 名称 | 分值 | 说明 |
| --- | --- | ---: | --- |
| `HOLIDAY_MAYDAY_CONTRIBUTION` | 五一出勤贡献 | +15 | 满足公司排班要求后后台确认 |
| `HOLIDAY_NATIONAL_DAY_CONTRIBUTION` | 国庆出勤贡献 | +15 | 满足公司排班要求后后台确认 |
| `HOLIDAY_BOTH_BONUS` | 五一国庆双节额外贡献 | +10 | 两个节假日均满足贡献认定 |
| `HOLIDAY_AVAILABLE_NOT_ARRANGED` | 节假日可出勤但公司未安排认定 | +10 / 节假日 | 队长可出勤且配合排班，但公司未安排 |

认定说明：
- 五一 / 国庆不是只带 1 天就自动给分。
- 队长需满足公司排班要求。
- 接龙后挑团、不接受合理安排、临时拒绝、失联，不认定节假日贡献。
- 公司未安排但认定，需要后台人工确认。

## 三、传播加分

传播类年度有效积分上限为 80 分 / 年。系统会在审核通过生成积分时按分类上限截断有效分，原始分值和有效分值写入规则快照。

| 规则编码 | 名称 | 分值 | 队长端申请 | 团期要求 | 限制 |
| --- | --- | ---: | --- | --- | --- |
| `MOMENTS_TRIP_SHARE` | 朋友圈带队分享 | +3 | 是 | 必须关联团期 | 每团最多 1 次 |
| `MOMENTS_DAILY_PROMO` | 朋友圈日常分享 / 推广 | +1 | 是 | 可不关联团期 | 年度传播上限 |
| `XHS_SIMPLE_POST` | 小红书简单分享 | +3 | 是 | 可不关联团期 | 同团小红书最多 1 篇 |
| `XHS_QUALITY_POST` | 小红书要求版分享 | +5 | 是 | 可不关联团期 | 与简单分享互斥，达标按 5 分 |
| `DOUYIN_VIDEO_HEARTS` | 抖音传播 | 动态 | 是 | 可不关联团期 | 每 10 个小红心 5 分，单条最高 30 分 |
| `VIDEO_ACCOUNT_HEARTS` | 视频号传播 | 动态 | 是 | 可不关联团期 | 同抖音传播 |

传播审核说明：
- 允许部分 AI 辅助润色。
- 不允许 AI 编造不存在的带队经历。
- 不允许搬运、伪造截图、伪造小红心数据。
- 虚假截图按虚假行为处理。

## 五、扣分与资格处理

| 规则编码 | 名称 | 分值 | 资格影响 |
| --- | --- | ---: | --- |
| `SMOKING` | 带队期间抽烟 | -20 | 记录扣分 |
| `LATE` | 队长迟到 | -20 | 记录扣分 |
| `UNIFORM_MISSING` | 未穿队服 | -5 | 记录扣分 |
| `MISSING_EQUIPMENT` | 未带基础物资 | -5 | 记录扣分 |
| `VALID_COMPLAINT` | 有效投诉 | -15 | 年度累计 2 次取消当年奖金资格 |
| `SERIOUS_COMPLAINT` | 严重投诉 | 0 / 特殊处理 | 年度积分清零，取消当年奖金资格 |
| `SAFETY_VIOLATION` | 安全违规 | -30 | 年度累计 2 次取消当年奖金资格 |
| `FAKE_BEHAVIOR` | 虚假行为 | 0 / 特殊处理 | 年度积分清零，取消当年奖金资格 |
| `REDLINE` | 红线行为 | 0 / 特殊处理 | 年度积分清零，取消当年奖金资格，并按原制度处理 |

扣分处理规则：
- 一次事件触发多个扣分项时，原则上按最严重项处理。
- 多个独立行为确需叠加时，由管理层确认。
- 每个扣分事件允许一次申诉。
- 申诉需在 3 个工作日内提交证据。

## 六、年度积分清零

触发年度积分清零：
- 严重投诉。
- 红线行为。
- 虚假行为。

当前 MVP 处理口径：
- 不删除历史 ScoreRecord。
- 不物理删除积分记录。
- 不批量作废历史积分。
- 奖金测算中将对应队长的奖金测算积分视为 0，并取消奖金资格。
- 后续可补充“年度积分清零处理流程”，保留处理原因、处理人、处理时间和证据说明。

## 七、奖金规则

奖金规则沿用 MVP 第二阶段测算口径：
- 满足基础资格的队长都参与分配。
- 年度完成带队次数 >= 8。
- 有效积分 > 0。
- 队长状态不是离职 / 暂停。
- 实习队长满足条件也可参与。
- 严重投诉、虚假行为、红线行为取消资格。
- A档：前 20%，权重 1.8。
- B档：20%-50%，权重 1.3。
- C档：50%-100%，权重 1.0。
- 单人封顶 2000 元。
- 封顶后余额不二次分配。
- 队长端不展示预计奖金金额。

公式：

```text
个人理论奖金 = 奖金池 ×（个人有效积分 × 档位权重）÷ 所有参与队长加权积分总和
```

## 八、前 50 榜单

队长端开放前 50 积分榜：
- 展示排名、队长昵称、队长等级、年度有效积分。
- 不展示手机号、身份证、扣分明细、投诉原因、奖金金额和非前 50 完整榜单。
- 队长本人可查看自己的排名、积分明细、加分记录、扣分项目和原因、奖金参与状态和不满足原因。

## 九、规则调整机制

- 积分规则允许中途调整，但必须设置生效日期。
- 新规则不追溯已生成积分。
- 已生成积分保留 `ruleSnapshotJson`。
- 历史修正走积分作废、重新生成或人工补录。
- 队长不需要强制确认已阅读规则。

## 十、试运营注意事项

- V2.2 规则从配置生效后向后适用。
- 历史错误数据不要直接改库，应走作废或补录。
- 节假日贡献、推荐、带教等后台确认型积分建议通过“专项加分”录入。
- data-check 会提示传播上限、每团重复、复购归属、投诉 / 安全 / 红线等风险。
